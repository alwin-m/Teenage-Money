# Project structure

- `index.html` — browser entry point.
- `src/main.jsx` — React entry point, screens, local state, add-money and expense flows, receipt overlay.
- `src/styles.css` — responsive visual system, dashboard, sheets, receipt styling.
- `src/finance.js` — pure amount, allocation, spending, and percentage helpers.
- `tests/finance.test.mjs` — Node assertion tests for core financial helpers.
- `README.md` — local setup and current scope.
- `dist/` — generated production output; ignored by Git.
