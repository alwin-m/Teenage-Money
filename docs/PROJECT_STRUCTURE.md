# Project structure

- `android/` — native Android application and Gradle build.
- `android/app/src/main/java/com/teenagemoney/app/ui/` — Compose screens, components, sheets, receipt overlay, and theme.
- `android/app/src/main/java/com/teenagemoney/app/data/` — SQLite helper, repository, and persisted models.
- `android/app/src/test/` — JVM tests for financial formatting and date calculations.
- `README.md` — local setup and current scope.
- `android/app/build/` — generated APKs and reports; ignored by Git.
